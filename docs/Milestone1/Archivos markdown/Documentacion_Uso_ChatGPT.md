# 3. Uso de Chat Gpt

**En la Documentación:** Para las tareas de generación de documentos chat gpt se ha utilizado principalmente como fuente para redactar un formato y una estructura qué cumpla una cohesión y coherencia. No obstante, no se ha usado siempre, solo en algunos puntos donde había dudas para explicar debidamente lo que se quería expresar.

**En Código:** Para las tareas de código el uso de chat gpt ha sido menor qué en la documentación, con una aportación casi inexistente. Esto es debido a qué la complejidad de las primeras tareas de código no generaban la necesidad de acudir a la ayuda qué proporciona dicha herramienta
