# 1. Introducción

Las reuniones de Daily Scrum deben durar un máximo de 15 minutos y todos deben

estar de pie. Cada persona debe decir lo que ha realizado. Toda la

reunión debe estar gestionada y controlada por el Scrum Master.

# 2. Contenido

\- Estado actual de la progresión del proyecto.

\- Revisión de tareas.

\- Problemas a solucionar.

\- Preparación de entrega.
