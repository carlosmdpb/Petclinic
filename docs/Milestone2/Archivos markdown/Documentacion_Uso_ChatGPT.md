# 3. Uso de Chat Gpt

**En la Documentación:** Para las tareas de generación de documentos ChatGPT se ha utilizado principalmente como fuente para redactar un formato y una estructura qué cumpla una cohesión y coherencia. No obstante, no se ha usado siempre, solo en algunos puntos donde había dudas para explicar debidamente lo que se quería expresar.

**En Código:** A diferencia del Sprint anterior, ChatGPT se ha utilizado más para las tareas de código que para las tareas de documentación. Se destaca su uso en Frontend durante este Sprint, ayudándonos a reducir considerablemente el tiempo de dichas tareas.
