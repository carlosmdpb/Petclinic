# 3. Uso de Chat Gpt

**En Código:** Para las tareas de código se ha reducido considerablemnte el uso de Chat GPT durante este Sprint, aunque cabe decir que nos ha servido de ayuda para realizar Frontend, pues es lo que más nos suele costar entender.

**En Documentación:** En este Sprint, al igual que en el primero, ChatGPT se ha utilizado más para las tareas de documentación que para las tareas de código. Destacamos su uso para ayudarnos a redactar de manera coherente y sobre todo, nos ha ayudado a entender algunos conceptos relevantes que presentaban alguna dificultad para seguir avanzando adecuadamente en el Sprint actual. Gracias a esto hemos podido ahorrar bastante tiempo en las tareas relacionadas con la documentación del proyecto.
